# Optimized Prompt for Replit: Multiple Data Source Integration for Fitout Cost Budget Tool

## Overview

I need to enhance the existing budget estimation application by adding support for multiple data sources and removing specific corporate branding. The application should retain its core functionality while providing users with the flexibility to choose their preferred cost data source for budget estimations.

## Key Changes Requested

### 1. Rebranding

- Remove all references to "MMC" throughout the application
- Rename the application to "Fitout Cost Budget Tool"
- Update any logos, color schemes, or design elements that contain corporate branding
- Ensure all documentation, help text, and UI elements reflect the new generic name

### 2. Multiple Data Source Integration

- Currently, the application uses CBRE cost data exclusively
- Add support for two additional data sources:
  - JLL Global Office Fit-Out Costs Guide 2025
  - Turner & Townsend International Construction Market Survey (ICMS) 2024
- Implement in phases: JLL integration first, followed by T&T after successful testing

### 3. Updated User Flow

- Maintain the existing step-by-step wizard approach
- After country selection (not city-specific), determine which data sources have information for that location
- Present available data sources to the user with a selection interface
- Allow for single source selection or multiple sources for comparison
- Adjust subsequent questions based on the selected data source's structure and available parameters
- Display appropriate assumptions when guide-specific data is missing

## Implementation Details

### First Phase: JLL Data Integration

#### Data Structure for JLL Guide

The JLL Global Office Fit-Out Costs Guide 2025 has the following characteristics:
- Data covers 68 cities across 40 countries
- Costs are structured around a 9-point pricing matrix with:
  - Three layout typologies: "Open & flexible," "High spatial variety," and "Structured"
  - Three quality levels: "Baseline," "Medium," and "High"
- Regional average costs are provided in USD/sqm
- Cost breakdown categories include:
  - Builders Works (37% of total costs globally)
  - M&E Services (29%)
  - Furniture, Fixtures, Equipment (13%)
  - Security, IT & AV works (12%)
  - Professional Services (8%)
- Reinstatement costs are provided by region

#### New User Interface Components

1. **Data Source Selection Screen**
   - Create a new step in the wizard after country selection
   - Display available data sources for the selected country with brief descriptions
   - Include option for comparison view if multiple sources are available
   - Provide visual differentiation between sources (possibly using their logos or distinct color coding)

2. **Adjusted Input Fields**
   - When JLL is selected, update the specification level options to match their terminology: "Baseline," "Medium," and "High"
   - Update layout type options to match JLL's typologies: "Open & flexible," "High spatial variety," and "Structured"
   - Maintain the existing area input, but ensure units are clearly labeled as square meters

3. **Results Display**
   - Create a new results template for JLL data that shows:
     - Total budget estimate based on JLL's costing structure
     - Breakdown of costs according to JLL's categories
     - Appropriate regional averages and benchmarks
   - When comparison mode is active, show results from multiple sources side-by-side with clear labeling

#### Handling Missing Data

- If the JLL guide doesn't have data for a specific country, clearly communicate this to the user
- Where specific parameters are missing (e.g., certain layout types), provide reasonable assumptions based on similar markets or global averages
- Include clear disclaimers about assumptions made
- Allow users to adjust assumptions if they have better information

### Backend Implementation

1. **Data Integration**
   - Create a new data model for JLL cost data following their 9-point pricing matrix
   - Develop mapping functions to translate between different data source terminologies
   - Implement data validation to ensure accurate calculations
   - Create helper functions to generate appropriate assumptions when needed

2. **Calculation Engine Enhancements**
   - Modify the calculation engine to handle multiple data sources
   - Implement source-specific calculation methods based on the selected guide's methodology
   - Ensure consistent units and currency handling across sources
   - Develop comparison algorithms for when multiple sources are selected

3. **Error Handling**
   - Implement robust error detection for missing or inconsistent data
   - Provide clear feedback to users when data limitations are encountered
   - Include fallback options when primary data sources are unavailable

## Future Phase: T&T ICMS Integration

After successful implementation and testing of the JLL data, the Turner & Townsend ICMS data will be integrated following a similar approach. The T&T data has different structures and methodologies that will require specific handling.

Key considerations for T&T integration include:
- Different cost categorization and breakdown
- Market-specific inflation rates and preliminaries
- Construction cost escalation factors
- Labor, material, and plant costs by market
