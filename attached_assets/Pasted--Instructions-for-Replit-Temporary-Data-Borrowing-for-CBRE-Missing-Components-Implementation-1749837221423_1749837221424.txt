# Instructions for Replit: Temporary Data Borrowing for CBRE Missing Components

## Implementation Strategy: Use T&T Data for Missing CBRE Components

### **Current Situation:**
- CBRE has: Construction, Furniture data ✓
- CBRE missing: Audio-Visual, Professional Fees ✗
- T&T has: All four components ✓

### **Temporary Solution:** Data Borrowing with Clear Attribution

## 1. Data Borrowing Logic

### **CBRE Calculation with T&T Supplements:**

```javascript
function calculateCBREBudget(projectData) {
  const cbreData = getCBRECosts(projectData.location, projectData.specification);
  const ttData = getTTCosts(projectData.location, projectData.specification);
  
  return {
    construction: cbreData.construction * projectData.area,
    furniture: cbreData.furniture * projectData.area,
    audioVisual: ttData.audioVisual * projectData.area, // Borrowed from T&T
    professionalFees: ttData.professionalFees * projectData.area, // Borrowed from T&T
    
    // Metadata for transparency
    dataSources: {
      construction: "CBRE",
      furniture: "CBRE", 
      audioVisual: "T&T (borrowed)",
      professionalFees: "T&T (borrowed)"
    }
  };
}
```

## 5. Easy Data Replacement System

### **Future CBRE Data Integration:**

```javascript
// Easy replacement when CBRE data becomes available
const CBRE_DATA_SOURCES = {
  audioVisual: {
    available: false,
    fallback: 'turner-townsend',
    dataPath: 'cbre.audioVisual' // Ready for future data
  },
  professionalFees: {
    available: false, 
    fallback: 'turner-townsend',
    dataPath: 'cbre.professionalFees' // Ready for future data
  }
};

function getCBREComponent(component, location, spec) {
  const config = CBRE_DATA_SOURCES[component];
  
  if (config.available) {
    return getCBREData(config.dataPath, location, spec);
  } else {
    return getTTData(component, location, spec); // Temporary fallback
  }
}
```
